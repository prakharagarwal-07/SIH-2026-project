# PackCheck Frontend Prototype

A simple frontend prototype for the SIH26034 PackCheck concept.

## Run in VS Code

1. Extract/open this folder in VS Code.
2. Open `index.html` in a browser.

Recommended:
- Install the VS Code extension **Live Server**.
- Right-click `index.html` → **Open with Live Server**.

## Files

- `index.html` — page structure and content
- `style.css` — complete styling and responsive layout
- `script.js` — navigation, demo upload interaction and login modal

## Important

This is currently a FRONTEND-ONLY prototype.

The upload button does not perform real OCR or AI analysis yet. It only simulates the workflow so you can test the UI.

The next step would be connecting:
Image upload → backend → OCR → information extraction → compliance rules → result.
